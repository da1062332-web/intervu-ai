# Custom Rules for Antigravity AI Coding Assistant

1. **Git Commit & Staging Rule**: Do not stage (`git add`) or commit (`git commit`) any local code changes without asking for and receiving explicit user permission first.
2. **Git Pull & Push Rule**: Always ask for and receive explicit user permission before executing any `git pull` or `git push` commands.
3. **Git Commit Message Rule**: Every time work or code changes are completed, always provide a clear, conventional, and descriptive Git commit message in your response.
